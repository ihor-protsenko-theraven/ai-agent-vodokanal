# Перелік вимог та доступів для розгортання системи на Production та підключення Asterisk

Цей документ містить вичерпний перелік технічних даних, доступів та конфігурацій, які технічні служби Замовника (системні адміністратори, адміністратори WSN, адміністратори АТС Asterisk) мають надати команді розробки для розгортання продуктивного контуру та підключення телефонії згідно з ТЗ «AI-агент для приймання та реєстрації заявок у WSN».

---

## Блок 1. Серверна інфраструктура та мережа (DevOps / Системні адміністратори)

Для забезпечення цілодобової роботи веб-інтерфейсу диспетчерів та потокової обробки аудіо дзвінків (до 100–1000 одночасних сесій згідно з ТЗ) необхідно виділити:

1. **Серверні потужності під Production-контур:**
   - **Конфігурація:** Мінімум 2 віртуальні машини (або кластер Kubernetes / Docker Swarm):
     - *Сервер застосунку та медіа-шлюзу (Web & Real-time Streaming):* від 8–16 vCPU, 32 GB RAM, 100 GB SSD.
     - *Сервер баз даних та журналів аудиту (PostgreSQL / Redis):* від 4 vCPU, 16 GB RAM, 200 GB SSD (NVMe).
   - **ОС:** Ubuntu 22.04 LTS або Debian 12.
   - **Середовище:** Docker 24+, Docker Compose v2.
2. **Мережеві налаштування та домени:**
   - Публічна статична IP-адреса для сервера.
   - Доменне ім'я для диспетчерського інтерфейсу (наприклад, `dispatcher.vodokanal.ua`).
   - Офіційний SSL/TLS-сертифікат (Let's Encrypt або Wildcard водоканалу) — обов'язковий для безпечного протоколу WSS (WebSockets) та роботи браузерного аудіо.
   - Відкриття мережевих портів:
     - `80/443 (TCP)` — веб-інтерфейс диспетчерів (HTTPS / WSS).
     - Повний доступ (без NAT/блокувань) між сервером додатку та сервером Asterisk для RTP-аудіотрафіку та команд управління.
3. **Мережевий доступ (White-list):**
   - Дозвіл вихідного трафіку з сервера додатку до:
     - API WSN (Forland);
     - Зовнішнього геокодера;
     - Google Cloud / API моделі розпізнавання.

## Блок 2. Інтеграція з WSN (Адміністратори Forland / WSN)

Взаємодія з системою WSN виконується в автоматичному режимі через службовий акаунт:

1. **Сервісний обліковий запис (Service Account):**
   - Створити окремого технічного користувача (наприклад, `wsn_ai_service`) та надати:
     - **URL API WSN:** точна адреса продуктивного інстансу (наприклад, `https://wsn1.forland-solution.com`).
     - **Логін та пароль** сервісного акаунта.
     - **Права доступу:** створення та зміна заявок класу `27772`, читання довідників `27994`, пошук заявок.
2. **Підтвердження та налаштування структури полів класу 27772 («Заявка(наряди)»):**
   - Підтвердити актуальність системних кодів полів:
     - `1958` — «Тип звернення» (значення з довідника `27994`);
     - `1972` — «Тип заявки» (значення з переліку `-12006`);
     - `1961` — «ПІБ заявника»;
     - `1960` — «Адреса проживання заявника»;
     - `-389` — «Текст адреси аварії»;
     - `-420` — «Координати» (WGS 84);
     - `1981` — «Телефон заявника»;
     - `1258` — «Дата й час аварії»;
     - `328` — «Примітки» (короткий зміст, сформований агентом).
   - Підтвердити статус для створення нової заявки: `5996` («На виконання»).
   - Підтвердити статуси відкритих заявок для перевірки дублів: `5041`, `5003`, `5996`, `5999`.
3. **Таблиця відповідності класифікації (Мапінг):**
   - Надати офіційну таблицю відповідності:
     $$\text{Тип звернення (довідник 27994)} \longrightarrow \text{ID типу заявки (перелік -12006)}$$
   - Підтвердити наявність у довіднику `27994` категорії **«Другое»** (використовується за замовчуванням, якщо точну проблему не визначено).
4. **Шаблон Deep-link для відкриття заявки оператором:**
   - Формат прямого посилання на відкриття картки у WSN за її ID (наприклад, `https://wsn1.forland-solution.com/Unit/Edit/{UnitID}`).

## Блок 3. Інтеграція з телефонією Asterisk (Адміністратори АТС)

Для отримання голосового потоку дзвінка, передачі даних у реальному часі та перехоплення розмови оператором:

1. **Інтерфейс передачі аудіопотоку (на вибір адміністратора АТС):**
   - **Варіант A (Рекомендований): Asterisk AudioSocket** (Asterisk 16+) — прямий стрімінг сирого аудіо (PCM 8kHz/16kHz) через TCP/Unix socket на сервіс AI.
   - **Варіант B: Asterisk REST Interface (ARI)** з підтримкою External Media (RTP streaming).
   - **Варіант C: SIP Forking / Eavesdrop (ChanSpy)** — дублювання медіа-каналу дзвінка на порт нашого медіа-шлюзу.
2. **Облікові дані та доступи до Asterisk:**
   - IP-адреса та порт сервера Asterisk.
   - Облікові дані доступу до ARI / AMI (логін, пароль, дозволені контексти).
3. **Пакет метаданих вхідного дзвінка:**
   - Налаштувати передачу параметрів виклику на момент старту дзвінка:
     - `Call ID` (унікальний ідентифікатор сесії Asterisk);
     - `CallerID / Номер абонента` (передається в поле `1981`);
     - `Timestamp дзвінка` (передається в поле `1258` за відсутності явно названого часу);
     - `Номер внутрішньої лінії оператора (Extension)` (наприклад, `101`, `102`).
4. **Сценарій перехоплення та переведення дзвінка (Dialplan):**
   - Налаштований контекст/план маршрутизації в Asterisk для:
     - *Команди перехоплення (Barge-in):* оператор натискає кнопку в браузері — лінія абонента миттєво підключається до гарнітури оператора.
     - *Автоматичного переведення:* якщо абонент вимагає оператора («покличте людину») або мовчить, дзвінок перемикається на вільну лінію оператора черги.
5. **Таблиця прив'язки диспетчерів:**
   - Документ зі списком операторів у форматі:
     `Внутрішній номер АТС (Extension)` $\longleftrightarrow$ `Логін користувача у WSN` $\longleftrightarrow$ `ПІБ оператора`.

## Блок 4. Географічні сервіси та адресні бази (ГІС / Адміністратори)

Згідно з розділом 9 ТЗ реалізується дворівневе геокодування:

1. **Рівень 1 (Пріоритетний): Внутрішній геодовідник WSN:**
   - Доступ (API / SQL-представлення / WFS) до бази географічних об'єктів водоканалу для пріоритетного пошуку вулиць, номерів будинків та отримання координат.
2. **Рівень 2 (Резервний): Зовнішній геокодер:**
   - Офіційний API-токен доступу до сервісу **Geodata.online** (DM Solutions: `https://api.dmsolutions.com.ua:2661`) або іншого комерційного геокодера.
3. **Межі зони обслуговування:**
   - Перелік міст, сіл та територіальних громад, які обслуговує підприємство (для фільтрації адрес за межами юрисдикції водоканалу).

## Блок 5. ШІ-моделі та ліцензії (AI / Cloud Management)

1. **Google Cloud / Gemini API (або погоджений Enterprise LLM-провайдер):**
   - Доступ до проєкту Google Cloud з увімкненим білінгом.
   - API-ключ (`GEMINI_API_KEY`) з доступом до моделей `gemini-3.7-flash` / `gemini-3.6-flash` (або Gemini Live API).
   - Погоджений ліміт запитів (Quota Tier) під очікувану кількість дзвінків (від 1000–3000 RPM).
2. **Синтез мовлення (Text-to-Speech):**
   - Доступ до сервісу озвучування українською мовою для режиму «голосове спілкування агента» (Google Cloud TTS / Azure Speech / альтернатива).

## Блок 6. Регламенти, графік та безпека (Керівництво кол-центру)

1. **Графік роботи:**
   - Розклад роботи кол-центру (робочі години, вихідні/святкові дні) — агент обробляє виклики виключно в ці години згідно з ТЗ.
2. **Пороги впевненості (Confidence Thresholds):**
   - Затвердити початкові числові пороги (значення від `0.0` до `1.0`):
     - Розпізнавання мовлення (STT): за замовчуванням `0.70`.
     - Класифікація звернення: за замовчуванням `0.75`.
     - Витягування адреси: за замовчуванням `0.80`.
     - Геокодування координат: за замовчуванням `0.80`.
   *(Усе, що нижче порогу, блокує пряме створення заявки та вимагає ручної перевірки оператором).*
3. **Політика маскування персональних даних:**
   - Погодження правил маскування ПІБ, номерів телефонів та адрес у журналах технічного моніторингу.
4. **Політика зберігання:**
   - Підтвердження регламенту видалення розшифровок дзвінків із внутрішнього журналу через 30 календарних днів.

## Додаток: Матриця відповідності кодової бази та ТЗ

| **Багатомовність (UA/RU/суржик)** | Тільки українська в системному промпті | Оновлення промпту Gemini для нормалізації до UA |
| **Поля `1958`, `1972`, `1961`, `1960`, `-389`, `-420`, `1981`, `1258`, `328`** | Реалізовано у `wsnConfig.PROPERTIES` | Готово (100% відповідність) |

| **Сервісний акаунт WSN** | Авторизація оператора Forland | Створення `Service Account` у Forland з ролевими правами |

| **Маскування PII та TTL 30 днів** | Логи без маскування | Впровадження маскування у логері та автоочищення розшифровок |
